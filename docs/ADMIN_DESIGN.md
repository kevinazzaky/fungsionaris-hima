# Arah tampilan admin

Membaca kebutuhan sebagai panel pengelola HIMA TI Undiknas dengan bahasa visual website yang ada: amber, putih hangat, dan Figtree/Rubik. ENERGY 1 / RHYTHM 1 / MOTION 1.

- Amber menandai tab aktif dan tindakan simpan; warna mengikuti identitas website.
- Latar terang mengikuti halaman publik dan membantu membaca tabel serta menilai foto tanpa tint gelap.
- Rubik untuk heading dan Figtree untuk isi mempertahankan tipografi yang sudah terpasang.
- Sidebar menunjukkan pekerjaan pengurus: pendaftar, fungsionaris, galeri, program kerja, serta pengaturan akun. Galeri memuat tab Galeri dan Hero beranda agar pengurus bisa berganti pengelolaan foto tanpa pindah halaman. Di bawah 1100 px, sidebar tersembunyi dan dibuka lewat tombol Menu pada header ringkas; desktop mempertahankan sidebar tetap.
- Tabel dipakai untuk perbandingan data pendaftar; baris foto dipakai untuk melihat konten sebelum edit. Tidak ada kartu statistik buatan.
- Form tambah/edit konten memakai popup native agar daftar tetap menjadi konteks di belakangnya. Pendaftar juga memakai dialog; fokus, keyboard dan Escape mengikuti perilaku native browser.
- Jarak rapat pada baris daftar, lebih longgar pada formulir; setiap kontrol utama minimal 44 px.
- Tidak ada ilustrasi, profil fiktif, atau aset baru. Avatar bawaan tetap digunakan jika foto belum diunggah.
- Gerak terbatas pada feedback bawaan kontrol; panel pengelola tidak memerlukan animasi dekoratif.
- Halaman akun memakai form satu kolom dengan label password yang jelas, petunjuk batas input, dan penjelasan bahwa pengguna perlu login kembali setelah perubahan.
- Cetak ulang ditempatkan pada detail pendaftar agar identitas diperiksa sebelum cetak. Kop, isi, ukuran A4 dan ruang tanda tangan memakai template publik yang ada; panel admin disembunyikan saat mencetak.
- Hero memakai daftar dan editor foto yang sama dengan galeri agar pengurus tidak perlu mempelajari pola baru. Konten terpisah karena foto hero tidak otomatis dipublikasikan di galeri. Dials tetap ENERGY 1 / RHYTHM 1 / MOTION 1 untuk admin; desain hero publik dipertahankan.
- Editor foto menampilkan foto tersimpan saat edit dan preview lokal ketika memilih file baru. Preview memakai contain agar gambar utuh dapat diperiksa; portrait untuk fungsionaris dan area lebar untuk hero/galeri. Batal pilih foto memulihkan gambar sebelumnya tanpa upload.
- Tab media mengikuti warna amber untuk pilihan aktif dan navigasi keyboard panah/Home/End. Tutup popup sebelum berganti tab; membatalkan popup membuang perubahan yang belum disimpan. Dials admin tetap ENERGY 1 / RHYTHM 1 / MOTION 1.
- Program kerja mengikuti popup editor dan daftar konten yang sudah ada. Ringkasan/deskripsi dipisahkan sesuai kartu dan modal publik; jadwal bebas teks mempertahankan rentang/semester. Preview utuh memakai contain dan publikasi dipisahkan dari status pendaftaran agar draft tidak tampil di website.
- Program kerja memakai tab periode, dengan periode terbaru sebagai pilihan awal. Kontrol tampil/sembunyi satu periode berada di atas daftar agar cakupannya jelas; label publikasi program dibedakan dari status periode. Tambah periode tetap melalui popup, tanpa menu sidebar baru. Tombol tab memakai aksen amber dan keyboard panah/Home/End.
- Halaman `/admin/program-kerja` tetap menjadi satu menu sidebar dengan tiga tab di bagian atas: **Daftar program**, **Atur formulir** (`?tab=formulir`), dan **Peserta proker** (`?tab=peserta`), dengan parameter opsional `?programId=<uuid>`. Ketiga tab memakai navigasi keyboard panah/Home/End, menyinkronkan URL melalui `replaceState`, menahan perpindahan tab saat ada dialog terbuka atau permintaan berjalan, serta meminta konfirmasi jika ada perubahan pada **Atur formulir** yang belum disimpan.
- Baris pada **Daftar program** menampilkan penanda mode pendaftaran (**Formulir Website** atau **Tautan Eksternal**), badge jumlah pertanyaan tambahan (`N kolom custom` ketika program internal memiliki minimal satu pertanyaan custom), badge kuota angkatan (`Kuota N angkatan` ketika pembatasan kuota per angkatan diaktifkan), ringkasan jumlah pendaftar (`N / M peserta` jika kuota diatur, atau `N peserta`), status publikasi, tombol **Atur formulir** (khusus program bermode **Formulir Website** untuk membuka tab **Atur formulir** yang sudah memilih program tersebut), serta tombol **Lihat peserta** untuk membuka tab **Peserta proker** yang sudah terfilter ke program tersebut.
- Popup tambah/edit program (`ProgramEditor`) tetap ringkas untuk metadata dan foto program: pilihan **Mode pendaftaran** (**Tautan Eksternal** mewajibkan URL saat status **Pendaftaran Dibuka**, sedangkan **Formulir Website (Internal)** menampilkan kotak pemberitahuan `.admin-notice` yang mengarahkan pengaturan kuota, tautan grup, tautan halaman publik, dan kolom custom ke tab **Atur formulir** tanpa merender `ProgramFormBuilder` di dalam dialog). Saat menyimpan metadata program, `registrationGroupLink`, `registrationMaxQuota`, dan `registrationFormConfig` yang sudah tersimpan tetap dipertahankan dan dialog langsung menutup; bila program baru dibuat dengan mode internal atau diubah dari mode eksternal ke internal, banner sukses (`.admin-notice-banner`) menampilkan tombol pintasan **Atur formulir `<judul>`**.
- Tab **Atur formulir** (`ProgramFormSettingsManager`) menyediakan tombol **Lihat peserta program ini**, pemilih **Pilih program kerja internal** (serta status memuat/error/muat ulang dan empty state **Belum ada program bermode Formulir Website** dengan tombol **Buka Daftar program**), dan editor berbingkai `#8c8c82` dengan dua kartu penuh lebar: **Akses, kuota & tautan grup** (status pendaftaran, **Kuota maksimal peserta (opsional)**, **Tautan grup WA/LINE peserta (opsional)**, toggle opsional berstatus awal nonaktif **Batasi kuota peserta per angkatan (opsional)** lengkap dengan preset cepat **2023-2026 @ 5 peserta**, tambah/hapus baris angkatan 4 digit hingga 20 entri/`MAX_COHORT_TIERS = 20` beserta ringkasan kapasitas, serta kotak `/program-kerja/[id]/daftar` dengan tombol **Buka halaman** dan **Salin tautan**) dan **Susunan kolom formulir** yang memuat `ProgramFormBuilder` penuh lebar (grid **Kolom bawaan formulir** 1 kolom di ponsel, 2 kolom mulai `540 px`, dan 3 kolom mulai `960 px`, dengan kolom bawaan **Angkatan** otomatis dikunci ke mode `required` selama kuota per angkatan aktif, serta **Pertanyaan tambahan custom** hingga 20 pertanyaan dengan urutan naik/turun dan opsi dropdown). Ketika toggle kuota per angkatan dimatikan, daftar tier sementara yang sudah diisi tetap dapat dipertahankan (`enabled: false`) atau kembali ke default tanpa `cohortQuotas` bila daftar kosong. Bilah simpan menampilkan status perubahan, **Reset perubahan** (memulihkan `baseline` dan menghapus error), dan **Simpan pengaturan formulir** (`PATCH /api/admin/programs/[id]/form`); perpindahan program, klik **Lihat peserta program ini**, atau perpindahan tab saat ada perubahan belum disimpan meminta konfirmasi terlebih dahulu, sementara pemuatan ulang saat bersih menyinkronkan `baseline` dan `draft`, dan saat ada perubahan aktif tetap memperbarui `baseline` tanpa menghilangkan editan yang belum disimpan.
- Tab **Peserta proker** menampilkan filter program kerja, pencarian (debounce 250 ms), tombol **Reset filter**, tombol **Unduh Excel (.xlsx)** sesuai filter program aktif, daftar responsif berbentuk kartu di layar sempit hingga tabel penuh mulai lebar `900 px` (menampilkan kolom per pertanyaan custom saat satu program dipilih pada filter, atau ringkasan pada kolom **Jawaban custom** saat menampilkan semua program), tombol **Detail & Edit** via dialog native (menyunting kolom bawaan aktif dan pertanyaan custom, menjaga program dan waktu daftar WITA, serta menampilkan bagian **Data bawaan terdahulu** dan **Jawaban kolom terdahulu** jika terdapat data lama sebelum perubahan konfigurasi), serta tombol **Hapus** dengan konfirmasi.
- Navigasi mobile memakai dialog native di sisi kiri, dengan lima tautan satu kolom dan akun di bagian bawah. Tutup/Escape/backdrop dan pemilihan tautan menutup menu; resize desktop membersihkan modal serta mengembalikan fokus ke navigasi desktop. Safe area, scroll internal dan tinggi dinamis menjaga akses kontrol pada landscape. Dials tetap ENERGY 1 / RHYTHM 1 / MOTION 1.
- Buka/tutup penerimaan berada di halaman Pendaftar, berupa switch berlabel dan teks aksi yang menjelaskan status. Pembaruan menunggu respons server, menonaktifkan kontrol selama simpan, dan menyediakan error/retry; tidak menambah menu sidebar.
- Menu **Pemilihan Ketua** tetap tampil di sidebar, namun `/admin/voting` saat terkunci hanya menampilkan layar PIN satu kolom (setup awal 2 input saat PIN database belum dibuat, form PIN dengan tombol tampil/sembunyikan 44 px saat terkunci, dan status fail-closed bila migrasi/database belum siap). Setelah terbuka, header menampilkan **Ganti PIN** (dialog verifikasi PIN saat ini) dan **Kunci Pemilihan Ketua** di samping **Muat ulang**.
- Popup memiliki judul yang menyebut jenis konten, tombol Tutup, dan form dengan Batal. Penutupan dikunci saat menyimpan; validasi gagal mempertahankan popup/isian. Latar tidak bisa digulir selama popup terbuka, dan fokus kembali ke pemicu setelah tutup atau simpan berhasil.
